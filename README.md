# giacomo

Raccolta di giochi per browser.

- [Caccia urbana](caccia-urbana/) — gioco 3D multiplayer non violento in un solo file HTML. Gioca: https://costalonga.org/giacomo/caccia-urbana/

- [Città Libera](citta-libera/) — città 3D open world in un solo file HTML: a piedi o con auto, moto, camion, elicottero e aereo; negozi, case, lavori, giorno e notte, multigiocatore. Gioca: https://costalonga.org/giacomo/citta-libera/

Realizzato da [@ginopizza](https://github.com/ginopizza).
